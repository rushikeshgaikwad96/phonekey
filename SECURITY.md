# Security Policy

## Reporting Security Vulnerabilities

The PhoneKey team takes security very seriously. If you discover a vulnerability or security issue, please do **NOT** open a public GitHub issue.

Please report vulnerabilities directly via email or designated private security disclosure channels:

- **Security Team Email**: `security@phonekey.local` (or file a private disclosure report on GitHub)

Include the following in your report:
- Detailed steps to reproduce the issue
- Affected components (Android App, Windows Agent, Credential Provider, Cryptographic Protocol)
- Proof-of-concept (PoC) code if available
- Impact assessment

We aim to respond to security reports within 48 hours and provide patches promptly.
